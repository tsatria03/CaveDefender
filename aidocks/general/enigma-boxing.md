**Boxing is gone.** From mid-2026 until 2026-11-24, `build/tools.py` had an optional post-compile stage that ran Enigma Virtual Box (`enigmavbconsole.exe`) to pack files *into* each exe: the client embedded its 5 audio DLLs and the whole `sounds/` folder, the server embedded 4 audio DLLs and its `docks/`. Projects lived in `src/client/cfc.evb` / `src/server/cfs.evb`, generated by `scripts/gen_cfc_evb.py` / `gen_cfs_evb.py`, and the embedded files were then stripped from the shipped folders. Screen-reader DLLs always stayed real files (an unresolved one means no speech at all), and the client's docks shipped loose so the in-game reader could open them.

**How it ended:** on 2026-11-23 the dev decided not to use Enigma any more and deleted both .evb files and both generator scripts. On 2026-11-24 the six-section plan [[build-tools-remove-boxing]] removed the stage from tools.py (the menu lost "Box only" and became 1-10; the CLI went from 5 flags to 4).

**What that means now:** every asset folder ships as an ordinary loose folder (client `lib, sounds, docks, data`; server `data, docks, sounds`), so players can see the sound files and hosts can edit the server's help and rules pages (both noted in the 5.3 changelog). The old boxing-only trap, where `file_exists()` returned false for embedded sounds, no longer applies ([[file-exists-boxed-sound-trap]]). The shared `~/.game_tools/tools.ini` never had an `enigma=` line (checked 2026-11-24), so nothing outside the repo needed cleaning. Don't reintroduce boxing without the dev asking.
